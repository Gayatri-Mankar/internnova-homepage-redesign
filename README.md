# InternNova Homepage Redesign

An independent homepage redesign concept created as a web development
project using HTML, CSS, and vanilla JavaScript.

## Project objective

Create a modern, responsive, user-friendly homepage inspired by the
InternNova platform while introducing an original visual design,
improved content hierarchy, and interactive elements.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive layouts using CSS Grid and Flexbox
- Intersection Observer API for scroll animations

No frontend framework or build process is required.

## Files

- index.html: Complete homepage
- style.css: Responsive styling and animations
- script.js: Navigation, filtering, FAQ, and animation interactions
- README.md: Project documentation

## Run locally

1. Download or clone the repository.
2. Keep all three source files in the same folder.
3. Open index.html in a modern browser.
4. Test the navigation, program filters, FAQs, and responsive layout.

Alternatively, use the Live Server extension in Visual Studio Code.

## Deploy with GitHub Pages

1. Create a GitHub repository.
2. Upload index.html, style.css, script.js, and README.md.
3. Open the repository's Settings.
4. Select Pages.
5. Choose Deploy from a branch.
6. Select the main branch and root folder.
7. Save and wait for the deployment to complete.
8. Open the published website URL and test it.
